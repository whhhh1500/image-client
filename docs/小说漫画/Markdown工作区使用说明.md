# 用 Markdown 制作剧本、分镜与漫画

## 从小说开始

在顶栏打开“小说漫画”，新建或选择小说，再添加章节并保存正文。保存正文只保存文字，不调用模型，也不会自动开始画图。

## 先设置整部作品的画风

章节工作区顶部提供“作品级画风参考”和“统一视觉宪法”：

1. 可直接上传图片作品，或从当前项目的图片资源中选择，最多 8 张。
2. 参考图按小说作品保存并跨章节共享；视频资源、其他项目和明确属于其他小说的图片不会进入候选。
3. 点击“根据参考图提取”会调用当前配置且支持图片输入的文本模型，生成可编辑的 Markdown 视觉宪法草稿。
4. 检查并保存视觉宪法后，再生成作品设定、剧本、分镜和每页 Prompt。所有这些 Agent 阶段以及 AI 优化都会读取同一版本的视觉宪法。

参考图片只用于提取和约束可迁移的线条、色彩、光影、材质、镜头与构图语言。系统不会把参考图中的具体人物、城市、建筑、剧情、文字、Logo 或固定版式当作本作内容。角色身份、服装、场景和道具仍应通过各自的文字锚点或专用参考角色管理。

接下来按需要使用这些文字成果：

1. **作品设定**：世界观、画风、人物基础锚点。一本小说共享这份设定。
2. **本章剧本**：剧情、场景与对白、本章对人物锚点的补充。
3. **分页分镜**：本章分成哪些页，各页各格发生什么、出现哪些文字。
4. **每页 Prompt**：一页一份完整绘图提示词，包含这一页需要的场景、人物、状态、分镜和对白。

这些内容都是 Markdown。可以用已配置的文本模型生成，也可以自己填写、修改或粘贴其他工具的结果。每份文档均可独立复制、导出为 `.md` 文件；只完成剧本或分镜就结束使用也完全可以。

## 已经有 Prompt

如果已经有一份完整的漫画页提示词，可以直接进入“每页 Prompt”添加页面，粘贴 Markdown 并保存。无需先生成其他文字文件。

提示词应包含实际绘图内容，避免只写“人物同上”“参考角色卡”。复制到其他生图工具时，应能在没有本应用上下文的情况下独立使用。

## 开始画漫画

页 Prompt 保存后，会检查必要内容是否齐全。缺少内容时直接列出需要补充的部分；“无新增”“无对白”可以作为明确的内容说明。

确认页 Prompt 已准备好后，点击生成该页；也可以选择批量生成已就绪的页面。文字生成完成不会自动开始图片生成。生成操作使用应用当前配置的服务，可能产生对应费用。

如果作品已保存画风参考，生图请求会同时携带视觉宪法文本和多张 `style` 参考图。每张结果会记录当时使用的视觉版本与参考图快照。之后修改画风时，旧图只会显示“需要更新”，不会自动重画。

生成过程中可以查看任务状态。某页失败时已经完成的图片仍保留；不要重复点击来等待结果。应用关闭中断的任务不会自动重新向服务商提交，重新打开后可以查看已保存的内容，再决定是否重试。

## 修改与连续性

人物锚点应分清基础特征和剧情变化：例如旧伤疤是基础特征，刚受的伤和获得的道具需要带到后续剧情，某一格举手只属于当前动作。

更新正文、设定或上游文档后，相关旧文档会显示“需要更新”。旧版本不会被清空，可以查看历史并复制。先核对或重新生成相关页 Prompt，再画新的漫画；旧图片仍可查看。

结构检查只能帮助发现缺少的部分，不能判断故事是否精彩或人物是否画得准确。请直接阅读 Markdown，检查剧情、人物状态和对白，再决定是否出图。

## 历史资料

旧小说分析、JSON 产物、批准和历史漫画工作台流程已移除，小说漫画只使用 Markdown 工作区。旧任务不会在启动时恢复生成，原数据库中的历史记录不删除；不再提供旧资料工作台入口。

通用短剧流水线、单独的图像生成、视频生成和资产库仍可照常使用。这次清理只涉及旧小说漫画流程。
