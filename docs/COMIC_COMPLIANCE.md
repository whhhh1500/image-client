# 小说漫画内容合规设计

## 范围

仅作用于“小说漫画”链路：作品设定、本章剧本、分页分镜、页面 Prompt、单页重画、最终画面 Prompt 和相关质检。普通图像页及“通用短剧 Agent”保持不变。

## 规则

- 保留追逐、对峙、危险动作、强光影和高反差构图等画面张力。
- 禁止鲜血喷溅、肢解、内脏、暴露伤口、尸体特写、虐杀和酷刑细节。
- 对暴力内容自动改用剪影、遮挡、画外表现、环境破坏、角色反应和动作余波。
- 现实品牌、商标、产品名、公众人物、明星及历史人物姓名必须自动改成虚构近似名称；不得输出或绘制真实 Logo、包装和可明确识别的商业标识。
- 对其他明显违法、色情、未成年人性化、仇恨或极端主义内容，优先改写为可安全表达的虚构情节；无法安全改写时停止该次生成并给出简短原因。

## 实现

建立一份后端统一的小说漫画合规规则，并注入所有文本规划阶段及最终画面 Prompt。最终出图编译再次附加同一规则，使章节 Prompt、原著内容和单页重画注入都不能覆盖它。质检阶段检查血腥表现、真实名称和真实标识，并要求自动改写后再输出。

已有作品不批量改写数据库；用户再次生成、同步、优化或重画时应用新规则。自动改名只保留虚构近似名称，并在同一作品的后续输出中沿用已有虚构名称，避免角色漂移。

## 验收

- 小说漫画各生成阶段均包含统一合规规则，其他两个生成入口不受影响。
- 含真实品牌、公众人物或历史人物的输入，输出要求明确为虚构近似名称且禁止真实标识。
- 冲突场景保留张力描述，同时明确禁止血腥和伤口细节，并给出安全替代表现方式。
- 自定义章节 Prompt 和单页重画 Prompt 位于合规规则之下，不能声明覆盖规则。
- 使用静态/单元测试验证 Prompt 拼装，不调用付费模型或图片服务。
